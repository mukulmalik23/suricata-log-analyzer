\# Suricata Log Analyzer



A live cybersecurity monitoring dashboard built using:



\* Suricata IDS

\* Docker

\* Python Flask

\* HTML/CSS



\## Features



\* Live traffic monitoring

\* HTTP event detection

\* JSON log parsing

\* Real-time dashboard

\* Source/Destination IP tracking

\* Dockerized deployment



\## Technologies Used



\* Suricata

\* Flask

\* Docker

\* Python

\* HTML/CSS



\## Project Architecture



Live Traffic → Suricata → eve.json → Flask Dashboard



\## Run Project



```bash

docker compose up --build

python app.py

```



Open:

http://127.0.0.1:5000
